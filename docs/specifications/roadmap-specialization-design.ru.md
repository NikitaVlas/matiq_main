## Поведение

В админке, в разделе видео и покрытия Roadmap, редактор создаёт направление или
навык, указывая родительское направление. Связь существующего навыка можно менять.
Допускается один уровень «направление → навык»; циклы запрещены. Названия Spider
Guard и Lasso Guard не зашиты в интерфейсе: источником данных служит база.

Чтобы навык стал доступен спортсмену внутри направления, нужно опубликовать видео
с метками этого навыка и нужной дисциплины. Повторная метка родителя не нужна:
видео автоматически входит и в подборку направления. Черновики и другая
дисциплина не открывают навык для нового выбора.

Спортсмен выбирает конкретные навыки, например только Spider Guard. Они заменяют
общее направление в его плане; очистка выбора возвращает направление. Повторный
assessment сохраняет выбор. Снятие последнего видео с публикации не удаляет уже
выбранный навык, но показывает отсутствие доступных материалов.

Списки навыков на карте изначально свёрнуты. Состояния «сейчас / далее / позже»
сохраняются. Одна цель с несколькими причинами рекомендации отображается одним
узлом; разные дисциплины и цели отдельных уроков не объединяются.

Новое самостоятельное направление не назначается всем спортсменам автоматически:
для него нужна связь с assessment или ручное добавление в план.

## Данные и проверки

Добавлена nullable-связь MetadataOption.parentId с индексом и внешним ключом.
Миграция не удаляет данные. Права редактора и принадлежность плана спортсмену
проверяются существующими механизмами; изменения связей записываются в аудит.

Проверка `node scripts/check-roadmap-skills.mjs` после сборки обоих API создаёт
собственную временную локальную БД, применяет миграции и проверяет создание связей,
публикацию, фильтрацию по дисциплине, выбор, повторный assessment, сброс выбора,
HTTP-валидацию и разграничение доступа. После выполнения удаляется только эта БД.
Браузерные тесты проверяют сворачивание, сохранение, ошибку записи и админку.
